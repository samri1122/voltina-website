# تصاویر سایت

این فایل‌ها را در همین پوشه قرار دهید:

- `about.jpg` — تصویر بخش درباره ما، پیشنهاد: 1200×900
- `free-consultation.jpg` — تصویر کارت مشاوره رایگان، پیشنهاد: 1200×900
- `hero/hero-main.jpg` — عکس بزرگ ابتدای صفحه، پیشنهاد: 1600×1200
- `hero/hero-01.jpg` تا `hero/hero-04.jpg` — چهار عکس کوچک گالری، پیشنهاد: 800×600

نام فایل‌ها باید دقیقاً همین باشد. فرمت WebP هم قابل استفاده است، اما در آن صورت پسوند را هم در کد مربوطه تغییر دهید.
