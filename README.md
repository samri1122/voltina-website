# سایت Voltina — نسخه‌ی Next.js + TypeScript

این پروژه، نسخه‌ی کامل سایت Voltina با Next.js (App Router) و TypeScript است. برخلاف نسخه‌ی قبلی HTML، اینجا فرم‌ها به بک‌اند جدا (Express) وصل نیستند — Next.js خودش هم فرانت‌اند و هم بخش سرور (API Routes) رو در یک پروژه‌ی واحد اجرا می‌کنه، یعنی فقط یک پروژه رو دیپلوی می‌کنید، نه دو تا.

## اجرا روی سیستم خودتان (برای تست)

نیاز به Node.js نسخه‌ی ۱۸ به بالا دارید.

```bash
npm install
cp .env.example .env.local
```

فایل `.env.local` رو با ایمیل و اطلاعات SMTP واقعی خودتون پر کنید (دقیقاً مثل نسخه‌ی قبلی — توضیح کامل ساخت App Password جیمیل در همون فایل هست).

```bash
npm run dev
```

سایت روی `http://localhost:3000` بالا میاد.

## ساختار پروژه

```
app/
  page.tsx              ← صفحه‌ی اصلی (همه‌ی بخش‌ها از کامپوننت‌ها ساخته می‌شن)
  layout.tsx             ← فونت، متادیتا و ساختار پایه‌ی HTML
  globals.css             ← تمام استایل‌های سایت
  blog/
    page.tsx              ← لیست وبلاگ
    [slug]/page.tsx        ← صفحه‌ی هر مقاله (پویا — از data/blog.ts خونده می‌شه)
  api/
    repair-request/route.ts   ← دریافت فرم تعمیر + ارسال ایمیل
    order/route.ts             ← دریافت فرم سفارش + ارسال ایمیل
    custom-project/route.ts    ← دریافت فرم پروژه + ارسال ایمیل

components/    ← تمام بخش‌های سایت (هدر، هیرو، فروشگاه، فرم‌ها، مودال‌ها و ...)
data/          ← داده‌های محصولات، نمونه‌کارها، خدمات، نظرات و مقالات (تایپ‌شده با TypeScript)
lib/           ← منطق ارسال ایمیل، اعتبارسنجی و محدودسازی درخواست (rate limit)
types/         ← تعریف انواع (interface) استفاده‌شده در کل پروژه
```

## تغییر محتوا

چون همه‌چیز تایپ‌شده (TypeScript) و داده‌محوره، برای اضافه/ویرایش کردن محصول، نمونه‌کار یا مقاله نیازی به دست‌زدن به کامپوننت‌ها نیست — کافیه فایل مربوطه در پوشه‌ی `data/` رو ویرایش کنید:

- محصول جدید → `data/products.ts`
- نمونه‌کار جدید → `data/portfolio.ts`
- مقاله‌ی وبلاگ جدید → `data/blog.ts`
- نظر مشتری جدید → `data/testimonials.ts`

## دیپلوی (انتشار سایت)

ساده‌ترین گزینه **Vercel** است (همون شرکتی که Next.js رو ساخته):
1. پروژه رو به یک ریپازیتوری گیت‌هاب push کنید
2. در vercel.com ریپازیتوری رو وصل کنید
3. متغیرهای محیطی (`NOTIFY_EMAIL`, `SMTP_HOST`, و بقیه از `.env.example`) رو در پنل Vercel وارد کنید
4. Deploy کنید — همین!

گزینه‌های دیگه (اگه نمی‌خواید از Vercel استفاده کنید): هر سروری که Node.js پشتیبانی کنه (VPS با `npm run build` و `npm start`، یا پلتفرم‌هایی مثل Liara).

⚠️ نکته: چون از فایل موقت (SQLite) برای ذخیره‌ی درخواست‌ها استفاده نمی‌کنیم (به‌خاطر سازگاری با هاست‌های Serverless مثل Vercel)، این نسخه پنل مدیریت (Admin) نداره — فقط ایمیل می‌فرسته. اگه به پنل مدیریت با تاریخچه‌ی درخواست‌ها نیاز دارید، بگید تا اضافه‌اش کنم (نیاز به یک دیتابیس واقعی مثل Postgres داره، نه SQLite فایلی).

## نسخه‌ی بدون بک‌اند (Static)

یک نسخه‌ی جدا هم براتون آماده کردم که اصلاً نیازی به سرور/API Route نداره — فرم‌ها مستقیماً از مرورگر به یک سرویس ایمیل ثالث (Web3Forms) وصل می‌شن. پوشه‌ی `voltina-static-noserver` رو ببینید.
